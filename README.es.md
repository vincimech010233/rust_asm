# Ejercicios de Rust, C y ensamblador

[English](README.md)

Archivo formativo de programación de bajo nivel con notebooks de Rust, programas de prueba en C y ensamblador x86-64.

Los directorios de ensamblador combinan pequeñas rutinas con programas C para comparar su comportamiento. Incluyen aritmética, cadenas, saltos, entrada y ejercicios sencillos.

## Estado

Son ejercicios independientes sin un sistema de compilación ni una suite de pruebas común. Revisa la gestión de memoria y las dependencias de plataforma antes de reutilizarlos.
